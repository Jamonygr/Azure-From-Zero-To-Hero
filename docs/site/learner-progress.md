# Your progress

Keep track of the lessons you have practiced and your quiz results in this browser.
Exercise and cleanup completion are **your own reports**, not automated proof of
Azure deployment, validation, removal, or cost status. Confirm the results using
each lesson's commands before marking them complete.

No account is required. Progress stays in browser-local storage; export a JSON
backup before clearing browser data. Import accepts only this course's version
1.0.0 format. It contains lesson status and scores, never credentials, Azure
resource IDs, Terraform state, tenant IDs, or subscription IDs.
